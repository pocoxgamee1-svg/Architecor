# Telegram Mini App — Маркетплейс

Тёмная фиолетовая тема в стиле твоих скриншотов.

## Файлы
- `index.html` — основная разметка
- `styles.css` — стили
- `script.js` — логика

## Как использовать

1. Загрузи все 3 файла на любой хостинг (GitHub Pages, Vercel, Netlify, свой сервер).
2. В BotFather создай бота → Menu Button / Web App → укажи URL твоего сайта.
3. Открой бота в Telegram — Mini App запустится.

## Функции

- **Главная** — сетка товаров (2 колонки)
- **Карточка товара** — детальный вид + кнопка «Купить»
- **Оплата** — страница как на твоём 3-м скрине:
  - Сумма в $
  - Примерный курс в ₽
  - Адрес TRC20 (USDT)
  - Кнопка «Подтвердить оплату»
- **Выложить товар** (кнопка + внизу) — только для владельца
- **Профиль → Настройки → Код** — введи `OWNERSSITE1` чтобы стать владельцем
- Цены всегда в долларах
- Товары хранятся в localStorage браузера

## Активация владельца
1. Перейди в **Профиль**
2. Нажми **Код владельца**
3. Введи: `OWNERSSITE1`
4. Теперь можешь выкладывать товары через кнопку **+**

## Важно
- Адрес кошелька сейчас тестовый: `TH82AANMK3x4r6tLX186WRqWmwisxWAxha`
- Замени его в `index.html` (или в script.js) на свой реальный TRC20-адрес
- Для реальной автовыдачи нужна серверная часть + проверка транзакций (сейчас только фронтенд)

## Локальный просмотр
Просто открой `index.html` в браузере (или через Live Server).
